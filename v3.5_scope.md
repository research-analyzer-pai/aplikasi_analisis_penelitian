# v3.5 scope and methodological notes

The v3.5 module adds four reproducible helpers: TF-IDF code suggestion against a researcher-authored codebook; coding coverage; code co-occurrence; and an editable joint display. These functions organize evidence and flag segments for further review. They do not autonomously perform open, axial, or selective coding and do not establish thematic saturation, validity, causality, or triangulation.

For a defensible workflow, preserve transcript IDs, anonymize participants, retain original quotations, document codebook revisions, inspect uncoded and contradictory evidence, record researcher decisions, and explain how quantitative constructs were conceptually harmonized with qualitative themes. PLS-SEM output remains exploratory; validate against established software and report the actual algorithm and settings.
