# v3.0 scope and validation notes

## Literature matrix
Imports user-supplied article metadata and organizes entries by theme/year. The app does not fetch articles, verify DOI/URLs, authenticate authorship, assess peer-review status, or validate extracted findings. Researchers must inspect source documents and correct metadata.

## Evidence-based synthesis outline
Produces a structured outline by user-entered theme and displays the supplied findings, limitations, and theory. It intentionally leaves synthesis and research-gap statements as researcher-authored prompts. It does not fabricate consensus, novelty, or citations.

## Instrument blueprint
Creates editable first-person draft statements from construct/dimension/indicator rows. Wording is generic and may not fit the construct, population, or cultural context. Expert content validation, cognitive interviews, pilot testing, item analysis, and construct validation remain necessary. It does not establish instrument validity.

## Dictionary-assisted coding
Matches researcher-defined terms in transcript segments and proposes candidate codes. Keyword matching is context-blind; negation, irony, synonyms, and implicit meaning can be missed. Researcher review and an auditable coding protocol are required.

## Test status
Unit tests cover input validation, thematic grouping, item generation, and dictionary matching. Tests do not validate substantive interpretations or methodological equivalence.
