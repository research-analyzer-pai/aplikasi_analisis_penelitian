# v3.2 scope and validation notes

## Crossref metadata discovery
Uses Crossref's public works endpoint for bibliographic metadata search. Returned records are candidate matches. Search ranking is not a quality ranking; metadata may be incomplete or incorrect. The feature does not retrieve full text, establish peer-review status, verify journal indexing, or conduct a reproducible systematic search. Record the query/date and screen sources manually for formal reviews.

## Qualitative intelligence
Provides a codebook template, frequency summaries, exportable coding records, and Cohen's kappa for two coders' aligned single-label nominal judgments. Kappa requires the same units in the same order and mutually exclusive labels. It is not appropriate without adaptation for multi-label coding, multiple coders, nested segments, or complex adjudication designs. Interpret with prevalence and sample-size context.

## Manuscript intelligence
Creates a structure from user-provided materials and an optional AI draft. The AI must not be treated as a source. Verify every citation, quotation, numerical result, and claim against primary materials. Do not claim journal readiness or acceptance. Follow target journal instructions and reporting standards.

## Testing
Unit tests cover metadata conversion, query validation, kappa edge cases, manuscript outline inputs, and codebook template. No live Crossref network test, real API call, or full Streamlit browser test is included.
