# v2.9 Research Intelligence: scope and responsible use

## Theory-to-indicator map
The user supplies theory name, theorist, construct, dimension, indicator, role, and source. The application checks completeness, duplicate indicators within construct/dimension, role labels, and alignment with hypotheses/estimated paths. It does not validate whether the selected theory is substantively appropriate.

## Hypothesis consistency
Each hypothesis maps a source construct to a target construct. When path estimates are available, the application checks whether the corresponding path exists. This is a structural check, not a test of theoretical plausibility.

## Interpretation
Path interpretation uses supplied beta and p-values. It describes estimated direction and statistical significance at the chosen alpha. It does not infer practical importance, causality, or theoretical mechanism.

## Chapter IV and V drafts
Drafts are generated only from user-entered mapping, path estimates, qualitative coding, and joint display. No citations, prior-study findings, participant quotes, or contextual facts are fabricated. Researchers must add verified literature, actual descriptive results, anonymized quotations, triangulation evidence, and limitations.

## Validation
The module is rule-based. Test structural cases and inspect output manually before including any narrative in a thesis or manuscript.
