# v2.7 Mediation and moderation scope

- Mediation: single mediator; a path from X to M; b and c' estimated together in Y ~ X + M; indirect effect a*b; nonparametric case bootstrap percentile 95% interval.
- Moderation: Y ~ X + Z + XZ on standardized estimated construct scores; reports interaction coefficient, OLS p-value, and bootstrap percentile interval.
- Bootstrap p-values are empirical sign-based approximations; interval is primary. Neither establishes causal identification.
- For a publication, specify temporal/theoretical ordering, assess confounding, measurement quality, sample design, and compare with validated PLS-SEM software.
