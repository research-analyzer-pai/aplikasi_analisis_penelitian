# Panduan Pusat Data Penelitian v5.2

1. Buka tab **Data**.
2. Unggah satu atau beberapa file sekaligus: Excel, CSV, Word, PDF, TXT, atau Markdown.
3. Sistem mengelompokkan file tabular dan dokumen teks.
4. Jika beberapa dataset tabular diunggah, pilih dataset aktif pada menu **Pilih dataset tabular untuk seluruh modul kuantitatif/SEM**.
5. Buka tab analisis kuantitatif/SEM atau kualitatif. Tidak perlu mengunggah file yang sama kembali.
6. Seluruh sumber yang sudah dimuat tampil dalam Ringkasan repositori data proyek.

Penyimpanan versi ini bersifat sesi aplikasi Streamlit. Unduh/ekspor data penting sebelum sesi berakhir. Jangan mengunggah identitas sensitif responden tanpa dasar etik dan perlindungan yang memadai.
