# v2.8 scope, interpretation, and validation

## HOC Two-Stage
Stage 1 estimates lower-order component scores. Stage 2 uses those scores as HOC indicators and estimates the supplied second-stage structural paths. Only reflective Mode-A LOC blocks are currently supported.

## Formative diagnostic
Indicator weights are estimated by standardized multiple regression against an explicit criterion. This can help inspect formative indicators but is not a full PLS Mode-B weighting procedure. Interpret VIF and weights alongside theory and content validity.

## Q²
The displayed Q² is an omission/cross-validation approximation on estimated construct scores. It is not PLSpredict and does not replace out-of-sample prediction assessment.

## MICOM-inspired check
The module compares pooled and group-specific Mode-A composites and uses permutation checks for compositional correlation and composite mean/variance differences. It is explicitly a MICOM-inspired diagnostic, not a certified canonical MICOM implementation. Do not use it to assert measurement invariance without independent validation.

## MGA
Permutation MGA is limited to two groups and compares group-specific path coefficients. It requires at least 20 complete cases per group. It does not include PLS-MGA, Welch-Satterthwaite, or Henseler MGA procedures.

## Validation checklist
- Compare coefficients, loadings, AVE/CR, R², HTMT, HOC paths, Q² and bootstrap intervals against a trusted PLS package.
- Test sample sizes, unequal groups, collinearity, non-normality, missingness, and random seeds.
- Validate MICOM and MGA using published benchmark datasets before reporting them in a paper.
