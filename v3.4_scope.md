# v3.4 scope, validation, and limitations

## Advanced qualitative workflow
The module validates codebook structure and parent-code references, chunks transcripts without splitting a segment, links codes to segment IDs, summarizes researcher review status, and builds a theme evidence table. Triangulation overview counts the sources and techniques recorded in coding metadata. It does not prove triangulation quality or establish saturation.

AI-assisted qualitative analysis remains optional through the AI Research Studio. AI output must be checked against source transcripts, negative cases, contextual meaning, reflexivity, and the study's analytic framework. Keep a secure audit trail and anonymize participants.

## Journal readiness
The checklist evaluates only fields entered by the researcher: title, abstract word count, keyword count, section presence, and references. It does not access journal websites, authenticate indexing, inspect publisher policies, verify all citation metadata, or predict editorial decisions. Obtain the current official author guidelines and complete journal-specific declarations and reporting checklists.

## DOI check
The DOI indicator detects DOI-like strings or doi.org URLs. Some legitimate sources do not have DOIs; missing DOI is not itself proof of an invalid reference.

## Validation status
Unit tests cover core transformations and input validation. No external API call, real journal portal submission, or full browser-level UI test is performed. PLS-SEM functions remain prototypes and are not certified equivalents of SmartPLS.
